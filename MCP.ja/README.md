# Vectorworks MCPサーバー

<a id="what-is-mcp"></a>

## MCPとは

Model Context Protocol（MCP）は、AIアプリケーションを外部の機能やコンテキストに接続するためのオープンプロトコルです。MCPサーバーは提供できる機能を記述し、MCPクライアントはその機能を検出して、共通のプロトコルでリクエストを送信できます。

<a id="vectorworks-local-http-server"></a>

## VectorworksのローカルHTTPサーバー

Vectorworks MCPサーバーは、MCPクライアントをVectorworksに実装された機能に接続します。実装は機能グループごとに整理されており、Vectorworks APIを使ってファイルのデータを確認、操作します。対象には、ファイルのコンテキスト、図面オブジェクトとジオメトリ、リソース、インターフェイスへのアクセス、スクリプト、製品固有のワークフローなどの領域があります。個々の機能の一覧は別途ドキュメント化されているため、このREADMEでは意図的にツールを列挙していません。

この実装は、ローカルのHTTP MCPサーバーです。ユーザーのコンピューター上で動作してHTTPでMCPクライアントと通信するため、互換性のあるクライアントは、ホスト型MCPサービスを経由せずにVectorworksのインスタンスに接続できます。

## 起動と接続

標準の作業画面（Viewerを除くすべて）では、**ツール > MCPサーバー > MCPサーバーを起動...** を選択します。カスタム作業画面では、コマンドが別の場所にある場合や、コマンドがない場合があります。**MCPサーバーを起動**ダイアログには、次の項目があります。

- **ツールモード**: **すべてのツールを有効化**（デフォルト）、**スクリプトツールを除くすべてを有効化**、または**スクリプトツールのみを有効化**。[ツールグループと有効化](v2027.2/Common.md#tool-groups-and-activation)を参照してください。
- **サーバーポート**: 1～65535、デフォルトは8765です。ポートが使用中の場合、サーバーは最大9個の別のポートを試し（65535を超えることはありません）、実際に使用しているポートを含むURLがダイアログに表示されます。
- **サーバーを起動**と**サーバーを停止**、およびサーバーURL（例: `http://localhost:8765`）をコピーする**URLをコピー**。
- AIスクリプトのドキュメントとMCPツールのドキュメントへのリンク、およびバージョン。

モードとポートを変更できるのはサーバーの停止中だけで、正常に起動すると保存されます。**閉じる**を選ぶとダイアログは閉じますが、起動中のサーバーは動作を続けます。サーバーを停止するには、**サーバーを停止**または**ツール > MCPサーバー > MCPサーバーを停止**を選択します。

MCPクライアントにURLをHTTP MCPサーバーとして追加し、Vectorworksでファイルを開きます。ファイルが開いていない場合、ツールは`no active Vectorworks document`を返します。サーバーの動作は次のとおりです。

- `127.0.0.1`のみで待ち受け、同時に1つの接続だけを処理します。
- MCPプロトコルバージョン`2024-11-05`と`initialize`、`ping`、`tools/list`、`tools/call`メソッドを使い、HTTP上でJSON-RPC 2.0を処理します。リクエストは`POST`（パスは任意）で送信し、`Content-Type: application/json`を指定します。
- `GET /`には`{service, version, protocol}`を返し、その他の`GET`には404、その他のメソッドには405を返します。
- `Host`が`127.0.0.1:<port>`または`localhost:<port>`以外の場合、送信された`Origin`が`http://`または`https://`に`localhost`または`127.0.0.1`と任意の`:<port>`が続く形式以外の場合（それ以外はすべて拒否され、`null`、`[::1]`、パスを含むものも拒否されます）、または`Host`か`Origin`が複数回送信された場合は、403で拒否します。`Content-Type`が単一の`application/json`ヘッダーではない`POST`は、415で拒否します。
- 認証はありません。このコンピューター上の任意のプログラムが、提供されたツールを呼び出せます。スクリプトの実行を無効にしておくには**スクリプトツールを除くすべてを有効化**を選び、使用しないときはサーバーを停止してください。
- `notifications/initialized`などの通知には、HTTP 200と空の本文で応答し、`capabilities.tools.listChanged: true`を通知します。クライアントが`text/event-stream`を受け付ける場合、`activateToolGroups`の応答は、結果の前に`notifications/tools/list_changed`を送るイベントストリームになります。

## AIを活用した固定スクリプト

AIは、繰り返し行う作業向けの固定スクリプトの開発（いわゆる「Vibe Coding」）も支援できます。実行のたびにAIクライアントに操作を動的に選ばせるのではなく、生成されたスクリプトを確認、テストしてから、実行中にAIが判断を行うことなく再利用します。

これにより、決定論的なワークフローを実現できます。スクリプトはあらかじめ定義されたロジックに従い、結果はその入力値とファイルの状態によって決まります。これらのスクリプトの作成方法と、開発時に使用するAIコンテキストについては、[Python APIドキュメント](../PythonAPI.ja/README.md)をご覧ください。
